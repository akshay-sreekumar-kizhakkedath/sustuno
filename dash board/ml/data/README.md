# SUSTUNO ML Data Pipeline & Feature Schema

## Overview
This directory contains the data extraction, validation, and feature schema definitions for the **SUSTUNO Dye Shade ML Model**.

The shade prediction model is a **supervised learning regression model** designed to learn:

$$\text{Material} + \text{Dye Recipe} + \text{Chemical Recipe} + \text{Process Parameters} \longrightarrow \text{Actual Measured } L^*a^*b^*$$

> [!IMPORTANT]
> **Supervised Learning Requirement**: Reference recipes, theoretical formulas, compatibility rules, and KB facts are **NOT** supervised training samples because they lack paired spectrophotometer-measured $L^*a^*b^*$ outcomes. The dataset extractor strictly excludes unvalidated and non-measured records.

---

## Files

- `feature_schema.json`: Versioned JSON schema defining inputs, target shade, and prediction targets ($measured\_L, measured\_a, measured\_b$).
- `extract_dye_batches.py`: Script to extract verified dyeing batch records from the Supabase database.
- `validate_dataset.py`: Validator to verify extracted datasets against numeric ranges, non-null target rules, and schema structure.
- `dye_shade_dataset_v001.json`: Versioned dataset manifest (generated by `extract_dye_batches.py`).

---

## Usage

```bash
# Extract dataset from connected Supabase database
python extract_dye_batches.py

# Validate dataset against feature schema
python validate_dataset.py
```
