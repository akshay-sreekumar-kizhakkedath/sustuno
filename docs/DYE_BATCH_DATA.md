# SUSTUNO — Dyeing Batch Intelligence

## Overview
Tracks planned vs actual dyeing runs to capture supervised empirical data for future ML model training.

## Features
- **Planned vs Actual Comparison**: `IMPLEMENTED` (Recipe, dye concentration, chemical dosage, liquor ratio, temperature, pH, process time).
- **Shade Result Recording**: `IMPLEMENTED` (Spectrophotometer $L^*a^*b^*$ input & $\Delta E_{76}$ calculation).
- **Deviations Calculation**: `IMPLEMENTED` (Reports recipe, process, and shade deviations).
- **Training Readiness Gate**: `IMPLEMENTED` (Excludes draft, incomplete, synthetic, or reference recipe records).
